准备阶段：
  [ ] 确保 Docker 和 Docker Compose 已安装
  [ ] 确保 MySQL / Orchestrator 容器配置正确
  [ ] 确保容器网络名称为：mysql-master, mysql-slave-1, mysql-slave-2
  [ ] 确保主机端口映射：3306→Master, 3307→Slave1, 3308→Slave2

部署阶段：
  [ ] 选择方案 A（快速替换）或方案 B（并行保留）
  [ ] 运行 deploy-docker-scripts.sh 或手动部署
  [ ] 设置脚本权限：chmod +x *.sh

验证阶段：
  [ ] Host 环境测试：bash monitor-raft.sh once
  [ ] Docker 环境测试：docker exec orchestrator-raft-1 bash monitor-raft.sh once
  [ ] 环境变量覆盖：ORCHESTRATOR_API=http://custom bash monitor-raft.sh once

原脚本的问题：
  ❌ 硬编码 127.0.0.1，在 Docker 容器内无法使用
  ❌ 无法自动发现运行环境
  ❌ 需要复杂的环境变量配置

增强脚本的优势：
  ✅ 自动检测运行环境（Docker/Host）
  ✅ 智能切换网络地址和端口
  ✅ 100% 兼容原脚本功能
  ✅ 支持环境变量覆盖
  ✅ 零配置无缝运行

使用体验改进：
  Host：bash monitor-raft.sh once         (立即生效)
  Docker：docker exec ... bash monitor-raft.sh once  (立即生效)
  Remote：ORCHESTRATOR_API=... bash monitor-raft.sh  (灵活配置)
